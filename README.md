# Maths Quiz App

A beginner Python maths quiz project built while learning programming fundamentals.

## Features

- Addition, subtraction, and multiplication questions
- Difficulty levels
- Replay system
- Score tracking
- High score tracking
- Input validation
- Randomly generated questions

## Technologies Used

- Python
- Git
- GitHub
- VS Code

This project helped me practice:

- Python functions
- Loops
- Conditionals
- Random number generation
- Error handling
- Git and GitHub workflow
- Debugging
